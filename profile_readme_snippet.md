## Tips for your profile README

1. **Pin the repository** — on your GitHub profile page, click "Customize your pins"
   and pin `quantforge`. It will show the description and star count prominently.

2. **Write a sharp repo description** — GitHub shows this under your pinned card:
   ```
   Production-grade algorithmic trading & backtesting library · mypy strict · Hypothesis tested · CI/CD
   ```

3. **Add topics** — on the repo page → Settings → Topics, add:
   `python`, `finance`, `algorithmic-trading`, `backtesting`, `quantitative-finance`,
   `pandas`, `numpy`, `pydantic`, `mypy`, `pytest`
   These improve discoverability and signal domain knowledge to recruiters.

4. **Enable the README preview** — your profile repo is `github.com/yourusername/yourusername`.
   Anything in its `README.md` renders on your public GitHub homepage automatically.
